# Запись в декатрон по катодным линиям

Date: 2026-11-07. TRS v0.56. Статус: **внесено в RTL**.
Ссылки: `sch/logic/DEKATRON_A110/README.md` §3.3, §5, §6, §9.10; `doc/board_estimate.md` §2.6;
REQ-DTV2-003, REQ-DTV2-007, OPEN-013, TC-N1.

## 1. Что было не так

Канал записи `WRCH_N16` — триод 6Н16Б в цепи возврата главного катода, сетка через
Cс ≈ 100 пФ / Rс ≈ 1M (README А110 §3.3). Лампа открыта — катод на −20 В и может гореть.
Лампа закрыта (перепад 100 В на сетке) — катод уходит на +150 В. Запись цифры i:
открытой остаётся только линия i, остальные закрываются, разряд гаснет и зажигается на
единственном катоде с −20 В:

```
открыта_k = ¬W ∨ sel_k        (в покое все линии 1)
```

RTL до v0.56 подавал на входы `WRCH_N16` и на модель декатрона одни и те же логические
сигналы. Владелец (2026-11-07): «это реальная проблема — нужно исправить». Разбор нашёл
три ошибки, а не одну:

| # | Где | Было | Физически |
|---|---|---|---|
| 1 | плата полной записи (Data) | вход канала k — `sel_k & SetData`: в покое все лампы закрыты | открыта_k = ¬W ∨ sel_k |
| 2 | Data, `SetZero` (CLRD, сбросы) | дешифратор включал только `SetData`, сброс шёл сразу в модель (`reset0_i`) | сброс должен идти через каналы: открыт только K0 |
| 3 | плата сброса 0/9 (IP, декады 1–4) | при `SetTop` закрывался только K0, общая шина K1…K8 висела на `SetZero` | общая шина закрывается и при SetTop: K0 = ¬SetTop, K9 = ¬SetZero, шина = ¬(SetZero ∨ SetTop) |

Ошибки 2 и 3 модель не ловила: у неё были отдельные логические входы `reset0_i` и
`resetN_i`, которых в приборе нет.

## 2. Решение (владелец, 2026-11-07)

**Модель декатрона на катодных линиях.** `DekatronTubeV2` и `DekatronTubeDelay`
принимают `line_open_i[9:0]` (1 — линия открыта) вместо `write_en_i`, `write_pos_i`,
`reset0_i`, `resetN_i`. В приборе одно событие:

- линия горящего катода закрыта не меньше `WRITE_MIN` — разряд переходит на единственную
  открытую линию;
- линия горящего катода открыта — ничего не происходит (так вела себя плата 0/9 при
  SetTop: разряд на K1…K8 оставался на месте);
- горящий катод закрыт, а открытых линий нет или больше одной — разряд зажигается где
  придётся: недопустимое воздействие (`$error` в модели на задержках, `invalid_dbg_o` и
  assertion в тактовой модели), разряд остаётся.

Пока закрыта хоть одна линия, подкатоды должны молчать (как прежде во время записи).
`RESET_MIN_*`, `EN_RESETN`, `RESET_N_POS` убраны, `RESET_MIN` объединён с `WRITE_MIN`
(решение владельца). Новый параметр `LINES` — катоды с цепью возврата. Катод без неё
(выше `MAX_DIGIT`, TC-N1) гореть не может, его линия всегда 0, а случайное включение
питания (`DEKATRON_RANDOM_INIT`) выбирает только среди `LINES`.

**`DekatronModule` получает уровни линий.** Порт `LineOpen[9:0]` (линии W0…W9 через
разъём) вместо `In_n`, `SetData`, `SetZero`, `SetTop`. Модуль только разводит их по
перемычкам своей платы:

- `WRITE = 1` — 10 каналов, линия k на катод k;
- `WRITE = 0` — канал K0 (`LineOpen[0]`), канал общей шины (`LineOpen[COMMON_LINE]`,
  первая линия кроме 0 и TOP) и при `TOP_LIMIT_MODE` канал TOP (`LineOpen[TOP_PIN_OUT]`).

Модель получает те же линии, какими их видит прибор на этой плате, поэтому ошибка
разводки на плате сброса проявилась бы в тестах.

**`DekatronCounter` строит уровни.** Дешифратор записи стоит вне платы декатрона, в клее
блока (`doc/board_estimate.md` §2.6). Для плат сброса — три линии на род декад
(с предустановкой в 9 и прочие): K0 = ¬SetTop (`NOT_N16`), K_TOP = ¬SetZero (`NOT_N16`),
общая шина = ¬(SetZero ∨ SetTop) (`NOR2_N16`). Для полной записи — `WriteLineDec`.

## 3. Ячейки вместо ABC

### 3.1 Дешифратор `WriteLineDec`

Первая версия отдавала функцию ABC — в клее блока и отдельным модулем с
`keep_hierarchy`. ApLine по зёрнам 0–3:

| Вариант | ApLine, среднее | Полная декада | Сотни |
|---|---:|---:|---:|
| до v0.56 (sel_k & SetData внутри `DekatronModule`) | 429,0 | 22,5 | ≈ 5 |
| открыта_k, ABC в клее счётчика | 465,8 | — | — |
| открыта_k, ABC, отдельный модуль | 463,6 | 35,5 | 16 |
| **открыта_k, ячейки вручную** | **434,3** | **27** | **8,5** |

Новая функция дороже старой на один уровень: старый выход `sel_k` — один анод ИЛИ-НЕ, а
¬W ∨ sel_k требует либо ещё инвертора, либо перехода через предекодирование. Ручная схема
(владелец: «собираем дешифратор на базовых ячейках»):

- пары разрядов A = (b1, b0) — 4 линии, B = (b3, b2) — 00, 01, 1x; цифра k — пересечение
  одной линии A и одной B (8 = 1x·00, 9 = 1x·01, коды 10–15 безразличны);
- линия «закрыть при записи» Xa_j = Set ∧ ¬(b1b0 = j) = `A1OOI(l1, l0, ¬Set)`, то же для
  B (`A1OOI`, `A1OOI`, `NOR2(¬Set, b3)` на 1x);
- линия «закрыть при сбросе» R_k: K0 — Top, K_TOP — Zero, остальные — Zero ∨ Top; общие
  для всех декад счётчика;
- выход: открыта_k = `NOR3(Xa_j, Xb_i, R_k)`.

| Часть | Ячейки | Ламп |
|---|---|---:|
| прямые литералы b0…b3 | 4 × `NOT_N16` | 2 |
| пара A | 4 × `A1OOI_N16J2` | 6 |
| пара B | 2 × `A1OOI_N16J2` + `NOR2_N16` | 4 |
| выходы | 10 × `NOR3_N16` | 15 |
| **полная декада** | | **27** |
| сотни (MAX_DIGIT = 2, TC-N1: пара B не нужна) | 2 × `NOT` + 3 × `A1OOI` + 3 × `NOR2` | 8,5 |

Сверка с формулой на всех входах (обе параметризации Data: TOP 5 / MAX 9 и TOP 2 /
MAX 2; idle, запись 0…9, сброс в 0, сброс в TOP) — совпадает. Модели ячеек для симуляции — `rtl/Logic/{NOR2_N16,NOR3_N16,NOT_N16,A1OOI_N16J2}.sv`
(`NOR2_N16` перенесён из `IpLine.sv`); в синтезе стоят сами ячейки.

### 3.2 Линии плат сброса

Те же три линии, отданные ABC выражениями `~{10{zero|top}} | …` в каждой декаде, стоили
IpLine +10 ламп (366,6 → 376,8 по зёрнам 0–3) при собственной цене ≈ 4,5: ABC
перестраивал клей вокруг `wr_zero` под новую полярность. Ячейками, по набору на род
декад, — 364,7.
