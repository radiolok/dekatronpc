## 1. Резюме

Инструмент пока не может принять то, что выдаёт проект компьютера. После решений владельца от 2026-10-09 (§5) понятно, что делать дальше.

- **Нетлист.** Он остаётся иерархическим (Q3): модули вроде `DekatronModule` — это готовые платы. Текущий парсер иерархию не понимает. Он молча склеивает одноимённые цепи разных модулей и не размножает подмодули (F1).
- **Модель совпадает с конструктивом.** Блок тула — это функциональный блок и ящик из 3–5 корзин (Q2, Q8). Совпадают также модуль 140×140 мм, слоты и провода (Q7, Q10, Q11).
- **Не хватает только разъёмов блока.** Нужны разъёмы HD-68 на другие блоки и общая разводка всех трёх блоков в одном проекте (F2, F4, Q1, Q9).
- **Приложение падает при запуске и не собирается.** Рефакторинг формата 0.3.0 не доведён до компонентов (F3).

## 2. Входные данные: что даёт проект и что ждёт тул

Синтез запускается командой `rtl/run/run_tests.sh -s`. Она вызывает `./synth` для IpLine, ApLine и MachineCtrl по отдельности. Скрипт `synt_dpc.tcl` делает `synth -top` без `-flatten` и пишет `<top>_synth.v`.

| Вход | Что даёт claude_nextGen | Что ждёт тул | Статус |
| --- | --- | --- | --- |
| Нетлист: форма | Иерархический Verilog. `DekatronModule`, `RelayMux` и `RelayEn` помечены `keep_hierarchy` | Один плоский модуль; границы `module` парсер не видит | **Несовместимо**, нужен иерархический парсер (Q3) |
| Нетлист: файлы | `IpLine_synth.v`, `ApLine_synth.v`, `MachineCtrl_synth.v`; в git их нет | Имя блока берётся из имени файла | Совпадает |
| Особые узлы | `DekatronTubeV2`, `OneShot`, `Impulse`, `RstTimeRelay` — особые ламповые узлы вне подсчёта ABC. Память при синтезе заглушена | Пользовательские элементы (REQ-PR-003) | Совместимо, но пины заводятся вручную |
| Liberty: путь | `rtl/vtube/vtube_cells.lib` | Тесты и README ищут `rtl/run/vtube_cells.lib` | **Устарело** |
| Liberty: ячейки | 27 ячеек, вывод `QN` у триггеров, `RELAY_2CO`, `GUIDE_EN_J2`, группа `relays(names)` | Парсер читает все 27; тест ждёт 23 ячейки со старыми именами | Парсер совместим, тест устарел |
| Тайминги | `rtl/vtube/vtube_timing.json` | Не читаются (REQ-PR-009 — после измерений) | Отложено |
| Модули KiCad | Плат модулей пока нет | Импорт `.net` (REQ-PR-004) | Входа нет ни у проекта, ни у тула |

Проверка на примере: два модуля, в каждом своя цепь `n1`. Парсер вернул одну цепь `n1` с четырьмя выводами из обоих модулей. Ячейки подмодуля, вставленного дважды, попали в список один раз. Сами вставки стали «ячейками» типа `$paramod\Sub`.

## 5. Решения владельца (2026-10-09)

| Вопрос | Решение | Что меняется в туле |
| --- | --- | --- |
| Q1. Что трассируем | Блок: N корзин (3–5) плюс разъёмы на другие блоки, разъёмов может быть несколько. Можно вести все три блока в одном интерфейсе и разводить весь компьютер сразу | Разъём блока — конец трасс; межблочные цепи в одном проекте |
| Q2. Единица размещения | Ряд в туле — это корзина | Ничего не меняется |
| Q3. Нетлист | Без `flatten`: модули нетлиста заменяются платами определённых типов (плата декатрона, плата реле) | Иерархический парсер, связь «тип подмодуля → ModuleType» |
| Q4. Трансформатор | Ширина кратна шагу сетки 12 мм: 72 + 12·K мм | `transformerWidth` задаётся в шагах сетки |
| Q5. Реле | На отдельных платах модулей. Экономия 5 ламп даёт 5 реле и новый тип модуля, поэтому от реле, возможно, откажемся | Обычный `ModuleType` |
| Q6. Память | Ферритовая память — отдельный блок, вне P&R | Для P&R это внешний пункт через разъём |
| Q7. Декатронный модуль | `DekatronModule` — одна плата | Один `ModuleInstance` |
| Q8. Блоки | IpLine, ApLine и MachineCtrl лежат по ящикам | `Block` = ящик |
| Q9. Разъём блока | Пока рассматривается кабель SCSI HD-68; на странице блока кабели сверху | Разъём на 68 контактов; ряд разъёмов над корзинами |
| Q10. Связи внутри блока | На соединительной плате корзины — только питание, всё остальное — проводами. В туле показывается либо связь между выводами, либо проложенный горизонтально или вертикально провод. Для отдельных случаев (декатрон + запись + считывание) — небольшие соединительные платы | Цепи питания не трассируются; тип «соединительная плата» |
| Q11. Набор плат | Фиксированного набора плат нет. Есть базовые элементы — из liberty и добавленные вручную (`Impulse`, `RstTimeRelay`). Тул знает, на каких выводах модуля стоит элемент и сколько их | Совпадает с моделью слотов |
