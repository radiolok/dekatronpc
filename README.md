# DekatronPC

Ламповый компьютер на декатронах А110 с системой команд Brainfuck. Счётчики машины — реверсивные декатроны: они умеют ровно то, что нужно Brainfuck, — прибавить и отнять единицу. Логика вокруг них — вакуумные лампы 6Н16Б и 6Ж2Б, без кремниевых полупроводников в вычислительном тракте.

*A vacuum-tube Brainfuck computer built around A110 dekatron counting tubes. RTL in SystemVerilog, an FPGA emulator for blocks not yet built, requirements and microarchitecture docs in Russian.*

## Машина

| Параметр | Значение |
|---|---|
| Архитектура | гарвардская: отдельные память программ и память данных |
| Система команд | один набор из 16 опкодов (ISA16): Brainfuck и шесть служебных, 4 бита на команду |
| Счётчик команд IP | 5 декатронов, 0…99999 |
| Счётчик вложенности Loop | 2 декатрона, 0…99; переполнение — аппаратная ошибка, машина замирает до сброса |
| Указатель данных AP | 5 декатронов; в RTL счёт замыкается 0 ↔ 99999 (предел 29999 — открытый вопрос OPEN-001) |
| Значение ячейки Data | 3 декатрона, 0…255 |
| Всего декатронов | 15 |
| Память программ | 100 000 × 4 бит, верхняя декада 99990…99999 — ПЗУ загрузчика |
| Память данных | 100 000 ячеек × 10 бит (BCD: сотни, десятки, единицы); физически — ферритовые кубы КП128/17-М70, до их установки память играет эмулятор на ПЛИС |
| Тактовая частота | 100 кГц (сборка по умолчанию; статический анализ по SPICE-задержкам ламп даёт минимальный период ≈ 9 мкс; тайминги самого декатрона — OPEN-013/014) |
| Логика | ≈ 1070 ламп + 15 декатронов А110 по синтезу RTL в библиотеку спроектированных ламповых ячеек (среднее по четырём зёрнам ABC, ±10), без памяти; бюджет 1200, цель — меньше 1000 |

Адреса и данные хранятся в BCD прямо так, как их показывают декатроны: память адресуется тетрадами без перевода в двоичный код. Цикл просматривается самой линией выборки: при `[` с нулевой ячейкой или `]` с ненулевой IP проматывается до парной скобки, счётчик Loop считает вложенность.

Конфигурация счётчиков проверена на наборе из ста реальных программ с GitHub — [Brainfuck-100](https://github.com/radiolok/bfutils/tree/master/programs/bf100) в сабмодуле `bfutils`: в 5 + 2 + 5 + 3 декатрона помещаются 97 программ из 100.

## Система команд

Один 4-битный набор, режимов нет (ISA16, [doc/isa16.md](doc/isa16.md)). Коды 0x0…0xA — Brainfuck.

| Опкод | Символ | Команда |
|---|---|---|
| 0x0 | `N` | NOP |
| 0x1 | `H` | HALT |
| 0x2 / 0x3 | `+` `-` | INC / DEC ячейки |
| 0x4 / 0x5 | `>` `<` | AINC / ADEC |
| 0x6 / 0x7 | `[` `]` | цикл по нулю ячейки |
| 0x8 / 0x9 | `.` `,` | COUT / CIN |
| 0xA | `0` | `[-]` — ячейка ← 0 (ставит MemLock) |
| 0xB | `S` / `E` | LD — начало загрузки; в потоке загрузки — её конец (EOT), в память не пишется |
| 0xC | `A` | CLRA — AP ← 0 |
| 0xD | `P` | MemLock — ставит флаг MemLock без загрузки: ячейка ← счётчик данных (копирование `>P<`) |
| 0xE / 0xF | `{` `}` | цикл по нулю AP (нужен загрузчику) |

Промотка считает `[ ]` и `{ }` вместе, поэтому вкладывать один вид в другой нельзя. Аппаратный сброс ставит IP = 99990 и запускает загрузчик `0<{0<}` … LD из верхней декады памяти программ, защищённой от записи (очистка памяти данных и загрузка с адреса 0); программный сброс обнуляет все счётчики, в том числе IP. EOT запускает программный сброс. Полная семантика, MemLock и ленивое чтение памяти данных — в [TRS.md](TRS.md), разделы 6–10.

## Сборка и проверка

```bash
git clone --recursive https://github.com/radiolok/dekatronpc.git
cd dekatronpc
git submodule update --init       # если клонировали без --recursive

docker build -t dekatron-pc .     # Verilator, Icarus, Yosys, cocotb — то же окружение, что в CI
# Quartus собирается отдельно: ./rtl/run/build_fpga.sh, CI — .github/workflows/fpga.yml
```

| Задача | Команда |
|---|---|
| один тест на Icarus | `cd tb && make test_compare SIM=icarus` |
| регрессия cocotb | `cd tb && make regression` |
| моделирование RTL | `cd rtl/run && ./run_tests.sh -t` |
| то же с моделью задержек ламп | `cd rtl/run && ./run_tests.sh -d` |
| синтез в лампы (Yosys), подсчёт ламп | `cd rtl/run && ./run_tests.sh -s` |
| RTL-тесты на нетлисте (`-t` — с задержками ламп) | `cd rtl/run && ./synth_sim.sh [-t]` |

Полная сборка DekatronPC и эмулятора в Verilator и синтез — тяжёлые задачи; на слабой машине начинайте с одиночных целей на Icarus. CI: `.github/workflows/` (`docker-image.yml`, `fpga.yml`, `web.yml`, `pages.yml`).

## Состояние

Версия требований — TRS v0.53 (2026-11-04).

- Готово в RTL: ISA16, модель декатрона и счётчик с завершением операции в такте приёма, IpLine / ApLine / MachineCtrl с предвыборкой и MemLock, банковая память, загрузчик в верхней декаде, терминал по UART.
- Проверка: golden model `bfutils/dpcrun` совпадает с RTL шаг в шаг (pi.bfk — 221 386 шагов, вывод `3.141`); cocotb, Icarus, Verilator, синтез и симуляция нетлиста (в том числе с задержками ламп из SPICE) идут в CI; есть симулятор в браузере.
- Ламповые ячейки (NOR, NAND, AOI, защёлки, триггеры) рассчитаны в SPICE и нарисованы в KiCad; на железе подтверждены только отдельные измерения (ёмкость ламп, блок питания).
- Открыто: OPEN-001 (предел AP), OPEN-007 (BELL), OPEN-011, OPEN-012, OPEN-013/014 (тайминги декатрона), OPEN-018. Следующие этапы: P&R-инструмент (REQ-PR-*), платы модуля декатрона, испытательный стенд, ферритовая память, первые ламповые модули.

Полный чек-лист — в TRS.md, разделы 19–22.
