# Генератор структурных схем

Скрипты, из которых получаются [SCHEMES.md](../../SCHEMES.md) и картинки `img/schemes/*.svg`. Схемы рисуются кодом на Python, без внешних библиотек и редакторов: каждый блок, провод и подпись задан координатами. При изменении RTL поправьте нужный лист и пересоберите всё одной командой. SVG и SCHEMES.md вручную не правьте: следующая сборка перезапишет правки.

## Сборка

```sh
python3 tools/schemes/build.py
```

Нужен только Python 3, запускать можно из любого каталога. Скрипт:

1. собирает все семь листов в HTML-страницу `tools/schemes/out/DekatronPC_schemes.html` и её автономную копию `out/preview.html` для просмотра в браузере (папка `out/` в git не попадает);
2. вырезает каждую схему в `img/schemes/<имя>.svg`;
3. переписывает `SCHEMES.md` в корне репозитория: текст листов, схемы, подписи, примечания и таблицы.

Чтобы проверить результат, откройте `out/preview.html` в браузере (поддерживаются обе темы) или посмотрите `git diff` по `img/schemes/` и `SCHEMES.md`.

## Файлы

| Файл | Что в нём |
|---|---|
| `build.py` | сборка: текст каждого листа, подписи к схемам, примечания о дефектах, таблицы; константа `RTL_REF` — с каким RTL сверены схемы |
| `sheet1.py` … `sheet7.py` | рисунки листов: 1 — модель декатрона, 2 — фазы и модуль, 3 — счётчик, 4 — IpLine, 5 — ApLine, 6 — MachineCtrl, 7 — верхний уровень |
| `lib.py` | класс `Fig`: блоки, провода со стрелками и подписями, логические элементы по ГОСТ 2.743, выводы, состояния автомата и переходы между ними |
| `head.html` | стили страницы: цветовые токены светлой и тёмной темы, классы элементов схем |
| `fallback.py` | дописывает фигурам атрибуты `fill`/`stroke` светлой темы — для просмотрщиков, которые не применяют CSS к SVG |
| `export_md.py` | экспорт страницы в `img/schemes/*.svg` и `SCHEMES.md`; список имён файлов `NAMES` |

## Как устроен рисунок

Каждая функция в `sheetN.py` создаёт `Fig(id, ширина, высота, aria)` и вызывает его методы в координатах `viewBox`:

```python
f = Fig("ipl", 1200, 470, "Линия выборки: ...")
f.box(560, 40, 210, 100, "DekatronCounter · IP", ["5 декад, 0…99999"])
f.wire([(420, 70), (560, 70)], label="valid · dec", lx=428, ly=63)
f.state("IDLE", 400, 60, "S_IDLE")             # автомат: состояние
f.edge("IDLE", "r", "FETCH", "l", label="...") # переход между сторонами состояний
return f.render()
```

Цвета задаются только классами из `head.html`: `w` — провод, `wacc` — выделенный путь, `wwarn` — дефект, `blk-opt` — блок, который есть лишь при параметре. Литеральных цветов в рисунках нет, поэтому страница сама переключается между светлой и тёмной темой. Отдельные SVG для GitHub получают светлую тему при экспорте.

## Изменить или добавить схему

- **Поправить рисунок:** функция в нужном `sheetN.py`.
- **Поправить текст, подпись или примечание листа:** `build.py`.
- **Добавить рисунок на лист:** новая функция в `sheetN.py`, вызов `fig(...)` в `build.py` и новое имя в `NAMES` (`export_md.py`) на той же позиции, где рисунок стоит на странице.
- **После сверки с новым RTL:** обновить `RTL_REF` в `build.py`.
